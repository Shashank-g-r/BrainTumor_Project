# 🧠 Brain Tumor Detection using Hybrid Deep Learning Techniques

A deep learning-based brain tumor classification system that combines Convolutional Neural Networks (CNN) and Vision Transformer (ViT) architectures to classify brain MRI images accurately. The project applies image preprocessing, hybrid feature extraction, and performance evaluation to improve medical image classification.

---

## 📌 Project Overview

Brain tumors are among the most life-threatening neurological diseases. Early detection from MRI scans can significantly improve treatment outcomes.

This project presents a hybrid CNN + Vision Transformer model that leverages both local feature extraction and global attention mechanisms for robust MRI image classification.
